Services d'infrastructure Windows Server 2025

Centraliser l'authentification, la résolution de noms et l'adressage automatique de l'ensemble du réseau.

Description

Installation et promotion d'un contrôleur de domaine Windows Server 2025 (création de la forêt). DNS intégré à l'Active Directory avec redirecteur pour la résolution externe. Serveur DHCP avec une étendue par VLAN et relais DHCP configuré sur les passerelles pour desservir les postes de tous les segments. Jonction des postes au domaine.

Difficultés rencontrées

  • Gestion du multihoming (interface secondaire parasite).
  • Nettoyage d'enregistrements DNS obsolètes après changement d'adresse.
  • Mise en place du relais DHCP inter-VLAN.
