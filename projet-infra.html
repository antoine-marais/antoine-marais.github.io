Infrastructure réseau & système d'entreprise

Une infrastructure d'entreprise complète, redondante et sécurisée, montée de A à Z sur le domaine de laboratoire antoinemarais.local — le projet phare pour l'épreuve E5.

4VLANs segmentés
2routeurs en HSRP
9/9tests de recette PASS

Contexte

J'ai conçu et monté l'infrastructure d'une PME simulée de 50 collaborateurs (quatre services) sur le domaine antoinemarais.local. L'objectif : un réseau fiable, tolérant aux pannes, segmenté et sécurisé — assemblé entièrement par moi-même, y compris le serveur physique.

Architecture réseau

  • Deux routeurs Cisco 898EA en HSRP (actif / secours, préemption, suivi de la liaison WAN par tracking) partageant une passerelle virtuelle pour la haute disponibilité.
  • Trois switchs Catalyst (2960 / 2960-X) : trunks 802.1Q, Spanning Tree Rapid-PVST+ avec racine primaire / secondaire forcée, agrégation de liens EtherChannel (LACP), routage inter-VLAN.
  • Quatre VLANs pour isoler les services (Administration, Production, Serveurs, Impression), avec NAT/PAT pour l'accès internet et administration sécurisée par SSH filtré.

Configuration réseau (extraits)

Extraits représentatifs des configurations Cisco IOS mises en œuvre sur le laboratoire.

Segmentation VLAN & trunk 802.1Q

! Switch S1 — création et nommage des VLANs
vlan 10
 name ADMINISTRATION
vlan 20
 name PRODUCTION
vlan 30
 name SERVEURS
vlan 40
 name IMPRESSION
! Lien montant vers le routeur — trunk 802.1Q
interface GigabitEthernet0/1
 switchport mode trunk
 switchport trunk allowed vlan 10,20,30,40

Root Bridge STP forcé

! S1 = Root Bridge primaire, S2 = secondaire
spanning-tree mode rapid-pvst
spanning-tree vlan 10,20,30,40 root primary

Redondance de passerelle — HSRP

! R1 — passerelle ACTIVE (priorité 110 + préemption)
interface GigabitEthernet0/0.10
 encapsulation dot1Q 10
 ip address 172.16.10.252 255.255.255.0
 standby 10 ip 172.16.10.254
 standby 10 priority 110
 standby 10 preempt
! ... idem pour les VLAN 20, 30 et 40
! R2 reprend les mêmes sous-interfaces en .253, priorité 100 (STANDBY)

Accès Internet — NAT/PAT

! Traduction d'adresses (PAT) du LAN vers l'interface WAN
ip access-list standard LAN-INTERNE
 permit 172.16.0.0 0.0.255.255
ip nat inside source list LAN-INTERNE interface Dialer0 overload
interface Dialer0
 ip nat outside
interface GigabitEthernet0/0.10
 ip nat inside

Accès distant sécurisé — SSH v2

! Durcissement de l'accès distant (volet détaillé en E6)
hostname R1
ip domain-name antoinemarais.local
crypto key generate rsa modulus 2048
ip ssh version 2
line vty 0 4
 transport input ssh
 login local

Systèmes & services

  • Windows Server 2019 (SRV-NAS-SIO1) : Active Directory (AD DS), DNS, DHCP et stratégies de groupe (GPO).
  • Virtualisation avec Hyper-V et une VM Debian 12 pour les services réseau.

Sécurité & durcissement

SSH v2 à la place de Telnet, ACL standard, NAT/PAT, isolation par VLAN et Root Bridge STP forcé. Le volet sécurité défensive complet est détaillé dans le projet de durcissement (E6).

Difficultés rencontrées

  • Identification du port WAN routé (Gi8) sur le switch intégré des 898EA.
  • Contrainte des numéros d'EtherChannel (1 à 6) sur les Catalyst 2960.
  • Génération de la clé SSH en mode interactif.
