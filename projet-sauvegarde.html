Sauvegarde automatisée 3-2-1

Une stratégie de sauvegarde résiliente selon la règle 3-2-1, conçue pendant mon stage : automatisée par un script Bash, planifiée avec cron, et répliquée sur un NAS et dans le cloud.

3-2-1règle appliquée
2 hfréquence auto

Objectif

Garantir la pérennité des données critiques en appliquant la règle 3-2-1 : trois copies des données, sur deux supports différents, dont une copie hors site (dans le cloud). Toute la chaîne s'exécute automatiquement, sans intervention manuelle.

Fonctionnement

  • Un script Bash utilise rsync --link-dest pour créer des snapshots incrémentaux économes en espace (les fichiers inchangés sont liés en dur).
  • Une tâche cron déclenche la sauvegarde toutes les 2 heures.
  • Les copies sont répliquées sur un NAS local et dans le cloud Backblaze B2 (copie hors site).
  • Une alerte mail via GLPI remonte le statut de chaque exécution.
#!/bin/bash
# Sauvegarde incrémentale 3-2-1
rsync -a --delete --link-dest="$LAST" "$SRC" "$DEST/$(date +%F_%H%M)"
# Réplication cloud
rclone sync "$DEST" b2:antoine-backups
# Planification (crontab) : toutes les 2 h
# 0 */2 * * * /opt/scripts/backup.sh
